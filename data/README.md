# Data

Generated by `src/audit_toolkit/generate_ledger.py` (run it from the project root to rebuild these files).

| File | Contents |
|---|---|
| `ledger.csv` | The payments the tests work on: invoice, date, vendor, category, amount. No labels. |
| `answer_key.csv` | For each invoice, whether it is a planted anomaly and which type. Only used to score the tests. |
| `missing_invoices.csv` | Invoice numbers removed from the sequence on purpose, for the sequence-gap test. |

All data is synthetic (made up).
